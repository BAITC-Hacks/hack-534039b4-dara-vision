# Third party materials

The unmodified participant package files (`environment.py`, `mock_environment.py`,
`scoring_core.py`, `local_eval.py`, `make_submission.py`, `agent_template.py`,
`PARTICIPANT_GUIDE.*`, the CSV dictionaries, `customer_profile.csv`, and `data/`)
were supplied for Beeline Tariff Marketing Campaigns Case by the HackAlem
organizers. Source: [official participant ZIP](https://drive.google.com/uc?export=download&id=1cQUKtE_cm9TVXgzpcFwQYYUpmuFaJHHT),
retrieved 2026-09-23; ZIP SHA-256 `df1d955fb97816ff6de8ceb142ed589915d969f43f840a650dcdfbe12734f20b`.

All other source files in this repository were written for this submission.
Python dependencies are NumPy, pandas and pytest; versions are pinned in
`requirements.txt`. No external API or secret is required at runtime.
